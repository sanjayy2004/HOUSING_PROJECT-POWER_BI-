# Power BI Projects

A collection of end-to-end Power BI projects covering data pipelines, DAX
modeling, and dashboard design across different domains — built as part of
my journey toward data analytics and GenAI engineering roles.

Each project below lives in its own folder with a detailed README covering
the data pipeline, DAX measures used, dashboard screenshots, and key
business insights.


## 🛠️ Tools & Skills Demonstrated

- **Power BI:** Desktop, Service, Dataflows, Gateway configuration
- **DAX:** CALCULATE, ALLEXCEPT, SUMX, MEDIANX, time intelligence (YoY, YTD), Decomposition Trees
- **Data Sources:** SQL Server, Google BigQuery, CSV
- **Data Preparation:** Power Query (profiling, cleaning, transformation)
- **Deployment:** Scheduled refresh, workspace publishing, report sharing
